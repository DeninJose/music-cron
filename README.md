Run the setup.sh script to setup weekly cron for automatic sync.

Run the download_audio.sh script to sync music playlists as audio downloads.

Run the download_audio_fast.sh script for a faster audio download mode (requires `aria2c`).

Run the download_video.sh script to download full videos from video playlists.

Run the download_video_fast.sh script for a faster video download mode (requires `aria2c`).

## IMPORTANT
Edit the config variables in the script to reflect the project directory and download directory

Add playlist urls to the txt file
